📌 Project Overview

This project focuses on analyzing employee and HR-related data to understand workforce trends, employee performance, attrition patterns, salary distribution, and department-wise insights. The dashboard was designed to help HR teams make informed, data-driven decisions through interactive visualizations and reporting.

🎯 Business Objective

The main objective of this project was to monitor employee performance, analyze attrition trends, and improve workforce planning through effective HR analytics and dashboard reporting.
